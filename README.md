## 📌 Sobre el proyecto

Rediseño profesional del sitio web de **MIERU**, un negocio de reparación y venta de consolas y mandos. La página combina una estética gamer con animaciones y objetos en 3D para atraer clientes y facilitar el contacto por WhatsApp.

## ✨ Características

| | |
|---|---|
| 🎬 **Portada gamer** | Video de fondo y objetos 3D interactivos |
| 🛒 **Catálogo** | Consolas y mandos con precios y compra por WhatsApp |
| 🔧 **Servicios** | Reparación de drift, botones, gatillos y diagnóstico |
| 👥 **Nosotros** | Misión, visión, valores y equipo |
| 📩 **Contacto** | Reserva de cita, reclutamiento y horarios |
| 📱 **Responsive** | Se adapta a celular, tablet y computadora |

## 🛠️ Tecnologías

- HTML5, CSS3 y JavaScript
- [Three.js](https://threejs.org/) para los modelos 3D
- Desplegado en [Vercel](https://vercel.com/)

## 🚀 Cómo ejecutarlo

1. Abre la carpeta del proyecto en **Visual Studio Code**.
2. Instala la extensión **Live Server**.
3. Clic derecho en `index.html` → **Open with Live Server**.

> Necesita conexión a internet para cargar Three.js y las fuentes.
